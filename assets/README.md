# 📁 Assets Directory

This directory contains media files for the All-Hack project.

## 📦 Contents

- **demo.gif** - Animated demonstration of the tool *(to be added)*
- **banner.png** - Static banner image *(optional)*
- **screenshots/** - Application screenshots *(optional)*

## 🎨 Demo GIF Requirements

The `demo.gif` should be:
- **Size**: 1200x600px (2:1 ratio)
- **Theme**: Dark & Minimalist
- **Colors**: #0a0a0a (bg), #00ff88 (primary), #ff0066 (secondary)
- **Duration**: 8-15 seconds
- **File Size**: Under 5MB
- **FPS**: 30fps

See [GIF_CREATION_GUIDE.md](./GIF_CREATION_GUIDE.md) for detailed instructions.

## 📝 Note

Until the demo GIF is created, the README will show a placeholder.
The GIF line in README.md is:

```markdown
![Demo](./assets/demo.gif)
```

To add your GIF:
1. Create the GIF using the guide
2. Name it `demo.gif`
3. Place it in this directory
4. Commit and push

The README will automatically display it!
